## View the Animation (Windows 64-bit)

1. Download the `Meteor Shower Animation.zip` file from the [latest release](https://github.com/Hirutiya/Meteor-Shower-Animation/releases/latest) on github.
2. Extract and open the `.zip` file.
3. Double-click `MeteorShower.exe` to launch the animation.

> **Note:** The pre-built `.exe` is for **64-bit Windows only**.

## Run the Sketch

1. Download and install [**Processing**](https://processing.org)
2. Clone or download the [repository](https://github.com/Hirutiya/Meteor-Shower-Animation)
3. Open `MeteorShower.pde` with Processing (There should be three tabs in total)
4. Click the **Run** button (the play icon)

## Build

1. Open `MeteorShower.pde` in Processing
2. Select **File** > **Export Application** from the top menu
3. Select the operating systems you want
4. Click the **Export** button
